# Dashboard Development Skill

본 스킬은 `TV P&L Analysis` 포털 디자인 가이드를 준수하여 21개 지사의 데이터를 실시간 교체하는 고가독성 오프라인 정적 대시보드 마크업 및 바인딩 기술을 정의합니다.

## 1. UI/UX 디자인 시스템 표준

1. **컬러 명세**:
   - `bg-primary`: Deep Navy `#051c2c` (사이드바 배경 및 테이블 메인 헤더)
   - `bg-secondary`: LG Red `#a50034` (기본 액센트 컬러 및 YoY 마이너스 증가 강조)
   - `bg-surface`: Soft Blue-Grey `#f6faff` (바디 배경색)
   - `border-slate-200` 및 `bg-white`: 컨텐츠 카드 및 테이블 영역 구분

2. **폰트 시스템**:
   - 대제목 및 헤더 타이틀: `Source Serif 4` 서체 적용.
   - 본문 텍스트, 카드 수치, 테이블 데이터: `Inter`, `Noto Sans KR` 샌스세리프 서체 적용.

3. **고정 스크롤 (Sticky) 및 레이아웃 구조 구현**:
    - 데이터 테이블은 가로/세로 모두 긴 구조를 가집니다. 사용자가 스크롤을 내릴 때 헤더(`thead th`)는 상단에 고정(`position: sticky; top: 0`)되어야 합니다.
    - 가로로 스크롤할 때 지표 명칭(첫 번째 `td`)은 좌측에 고정(`position: sticky; left: 0`)되며, 뒷배경 데이터가 비쳐 보이지 않도록 `background-color: #ffffff` 처리를 해야 합니다.
    - **레이아웃 오버플로우 방지 및 세로 스크롤 제거**: 메인 콘텐츠 `main` 태그에 `min-w-0` 클래스를 부여하고 `html, body { overflow-x: hidden; }` 스타일을 선언하여 가로 스크롤을 오직 `.table-container` 안에서만 동작하도록 가둡니다. 또한, 테이블의 세로 방향 `max-height` 및 `overflow-y` 제한을 제거해 모든 데이터 행이 스크롤 없이 전부 노출되도록 유도합니다.
    - **탭 메뉴를 활용한 테이블 단일 전환**: 3개 테이블(PSI 지표, 손익 지표, 경쟁 지표)은 단일 선택형 탭 단추 클릭에 따라 상응하는 테이블 하나만 화면에 노출하고 나머지는 감춥니다.

## 2. 핵심 구현 및 바인딩 로직

1. **지표 계층 구조(Hierarchy) 분석**:
   - 엑셀 시트 행은 계층 구조에 따라 머지되어 있으며, 파싱된 5단 라벨 객체(`labels: [G, H, I, J, K]`)에 분산 기입되어 있습니다.
   - 중복 레이블 표기를 없애기 위해 **역방향 스캔**을 수행하여, 가장 우측에 있는 비어있지 않은 문자열을 지표 노드의 최종 명칭(Display Name)으로 사용하고 해당 문자열이 있던 배열의 인덱스(0~4)를 들여쓰기 레벨(Indent Level)로 적용합니다:
     ```javascript
     function getRowDisplayNameAndIndent(labels) {
         let indent = 0;
         let text = '';
         for (let i = 4; i >= 0; i--) {
             if (labels[i] !== null && labels[i] !== undefined && String(labels[i]).trim() !== '') {
                 indent = i;
                 text = String(labels[i]).trim();
                 break;
             }
         }
         return { text, indent };
     }
     ```

2. **6종 요약 카드 매핑 (YTD 6월 기준 및 순서)**:
   - 순서: Net Sales -> 영업이익 -> 영업이익율 -> Sell-in 수량 -> Sell-out 수량 -> 유통재고
   - **Net Sales**: Row 50의 상반기 누적(H1, index 6) 컬럼값 및 YoY 연동. 화폐 단위로서 원본 USD 값을 `1,000,000`으로 나누어 백만 단위(`M`)로 변환하고, 천 단위 콤마와 소수점 1자리를 표기합니다 (예: `$1,254.4M`).
   - **영업이익**: Row 59의 상반기 누적(H1, index 6) 컬럼값 및 YoY 연동. Net Sales와 동일하게 백만 단위(`M`) 및 천 단위 콤마 표기를 적용합니다.
   - **영업이익율**: Row 65의 상반기 누적(H1, index 6) 컬럼값 및 YoY 연동. 비율 단위로서 `val * 100` 계산 후 `%` 단위를 부착합니다.
   - **Sell-in 수량**: Row 19의 상반기 누적(H1, index 6) 컬럼값 및 YoY 연동. 수량 단위로서 천 단위 콤마를 포함한 순수 정수로 표기합니다 (예: `2,488,659`).
   - **Sell-out 수량**: Row 24의 상반기 누적(H1, index 6) 컬럼값 및 YoY 연동. 수량 단위 표기를 적용합니다.
   - **유통재고**: Row 28의 6월 말(June, index 5) 컬럼값 및 YoY 연동. 수량 단위 표기를 적용합니다.
   - **카드 UI 레이아웃 구성**:
     - 카드는 4개의 요소를 한 행씩 수직으로 누적(Stacked Layout)하고 왼쪽 정렬합니다.
     - **Line 1**: 지표 타이틀 (예: `NET SALES`)
     - **Line 2**: 실적 데이터 수치 (예: `$1,254.4M` 또는 `2,488,659`)
     - **Line 3**: YTD 기간 정보 (예: `YTD (6월 누적)`)
     - **Line 4**: 전년비 증감 배지. 금액/수량 지표는 배지 내부에 전년 대비 **절대 증감치**와 **증감율**을 병기합니다 (예: `-$8.5M (▼0.7%)` 또는 `-120,750 (▼4.6%)`). 영업이익율은 절대 차이 병기 없이 증감율만 표시합니다 (`▲4.4%p`).

3. **인메모리 스위칭**:
   - 사이드바의 21개 국가/지사 버튼을 누르면 브라우저 새로고침이나 iframe 통신 없이, 임베드된 `kpiData` 객체에서 현재 법인 코드의 데이터를 찾아 DOM 엘리먼트(카드, 테이블)를 바닐라 JS로 즉시 업데이트합니다.

4. **YoY 증감율 색상 강조 (요약 카드 배지)**:
   - 전년비 YoY 증감율은 양수와 음수의 변화에 따라 배지의 텍스트 및 테두리 색상을 다르게 표현합니다:
     - 일반적인 지표: 증가 시 녹색 계열, 감소 시 적색 계열.
     - WOS 및 DIO와 같은 재고 지표: 감소 시 녹색 계열(긍정), 증가 시 적색 계열(부정).

5. **데이터 테이블 분할 구성**:
   - 기존의 단일 '당해 실적' 표 및 'YoY 증감율' 표를 없애고, 데이터를 **'PSI 지표'**, **'손익 지표'**, **'경쟁 지표'**의 3개 분리된 표로 구성합니다.
   - **PSI 지표 (Table 1)**: Sell-in 수량(OLED, QNED, 신모델, 구모델 포함), Sell-out 수량(OLED, QNED, 신모델, 구모델 포함), 신모델 Sell-in 비중(수량), 신모델 Sell-out 비중(수량), 유통재고(신모델, 구모델 포함), WOS(-4)(신모델, 구모델 포함)를 포함합니다.
      - **신모델 비중 행 들여쓰기**: `신모델 Sell-in 비중(수량)` 및 `신모델 Sell-out 비중(수량)` 행은 `유통재고` 바로 위에 위치하며, 들여쓰기 깊이를 `유통재고`와 동일하게 `indent = 1`로 구성합니다.
      - **비중 행 표기 단위**: 소수점 없이 정수 백분율(`00%`) 형식으로 표기합니다.
   - **WOS 지표 표기 규칙**: WOS(-4) 및 그 하위 모델(신모델, 구모델)은 정수가 아닌 소수점 1자리(예: `7.2`, `-18.7`) 형식으로 고정 표기합니다.
   - **Sell-out 하위 OLED 및 QNED 연산**: 
     - 엑셀 시트의 19~33행에는 Sell-out의 OLED와 QNED 세부 지표가 누락되어 있습니다. 이를 위해 196~293행에서 신모델 OLED(198행) + 구모델 OLED(248행)를 합산하여 Sell-out OLED를 계산하고, 신모델 QNED(213행) + 구모델 QNED(260행)를 합산하여 Sell-out QNED를 계산한 뒤 가상 행으로 주입하여 Sell-in과 동일한 하위 구성을 제공합니다.
     - **2025년 시트(KPI(25년))의 레이아웃 불일치 보정**: 2025년 시트는 지표 구성 행 번호가 다르므로 데이터 수집 시 반드시 신모델 OLED는 **Row 195**, 신모델 QNED는 **Row 207**, 구모델 OLED는 **Row 242**, 구모델 QNED는 **Row 254**를 참조해 합산해야 정확한 전년 실적이 산출됩니다.
   - **손익 지표 (Table 2)**: 제목을 '손익 지표 (P&L Index)'로 명명하며, Gross매출, G.ASP, 차감, Net매출(제상품), Net매출, 한계이익, 영업이익 등을 포함합니다 (엑셀 행 index 38~67).
     - **Net매출(제상품) 표기**: 신모델(제상품) 위의 Net매출 행의 레이블은 'Net매출(제상품)'으로 구성합니다.
     - **금액/손익 지표 백만 단위 통일**: Gross매출, Net매출(제상품), Net매출, 한계이익(금액), 영업이익(금액) 및 하위 모델 항목들은 항상 `$0,000.0M` (백만 단위 및 소수점 1자리) 형식으로 표기합니다.
     - **ASP 지표의 소수점 규칙**: G.ASP($) 및 하위 모델은 소수점 없는 정수(예: `$661`), N.ASP($) 및 하위 항목은 소수점 1자리(예: `$660.7`) 형식으로 표기합니다.
     - **차감 및 비율 지표 규칙**: 차감(하위 항목 포함), 한계이익(%), 영업이익(%) 및 하위 항목들은 모두 소수점 1자리 `%` 형식으로 표기합니다.
    - **경쟁 지표 (Table 3)**: 제목을 '경쟁 지표 (Competitiveness Indicator)'로 명명하며 전시수량, 전시지수, 시장판가, M/S 등을 포함합니다 (엑셀 행 index 73~93).
      - **지표 명칭 표기 및 구분**: 각 행의 레이블에는 parent category명을 포함하여 명시적으로 구분합니다 (예: `전시수량 (TTL)`, `전시지수 (OLED)`, `시장판가 (LG)`, `M/S (LG)`).
