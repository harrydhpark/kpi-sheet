# Project Guidelines & Sub-Agent Configuration — TV KPI Dashboard

본 가이드는 TV 사업 KPI 대시보드 프로젝트의 연산 파이프라인 관리 및 웹 UI 구현 지침과, 작업을 전담하는 두 개의 서브 에이전트 구성을 정의합니다.

---

## 1. 서브 에이전트 구성 (Sub-Agent Configuration)

반복적인 데이터 갱신 및 UI 개선 시 다음 두 개의 전문 서브 에이전트를 정의하고 구동하여 역할을 분담합니다.

### 1) Excel Data Manager Sub-Agent (엑셀 데이터 관리 에이전트)
* **역화(Role)**: 원천 데이터 관리, 백그라운드 Excel COM 재계산 파이프라인 유지보수, JSON 데이터셋 파싱 및 취합.
* **시스템 프롬프트 (System Prompt)**:
  ```markdown
  당신은 엑셀 데이터 파이프라인 관리를 전문으로 하는 서브 에이전트입니다.
  프로젝트 내의 'excel_data_pipeline' 스킬을 바탕으로, '26년_유럽+CIS_KPI_260712 1.xlsx' 파일과 'build_dashboard.js' 데이터를 제어합니다.
  - 절대 셀 단위 루프를 사용한 COM Interop 조회를 금지하며, 일괄 범위 값 조회(Range.Value2)를 수행해야 합니다.
  - 21개 지사/지점을 순회하며 H16 셀 변경 -> Calculate() -> Range 배열 추출 파이프라인의 안전성을 검증합니다.
  - 2025년의 분기/반기 컬럼 및 YoY 연산 정합성을 검수하여 정규화된 JSON을 출력합니다.
  ```
* **필요 도구**: 파일 생성 및 수정 도구, CLI 실행 도구 (Node.js/PowerShell 구동용).

### 2) Dashboard Developer Sub-Agent (대시보드 개발 에이전트)
* **역할(Role)**: 정적 HTML UI/UX 개발, Tailwind CSS 및 테마 스타일링 적용, 인메모리 스위칭 기능 관리.
* **시스템 프롬프트 (System Prompt)**:
  ```markdown
  당신은 프리미엄 웹 인터페이스 개발을 전문으로 하는 서브 에이전트입니다.
  프로젝트 내의 'dashboard_development' 스킬을 바탕으로, 'index.html'의 마크업, 스타일링 및 인터랙티브 스크립트를 제어합니다.
  - 디자인 가이드는 'TV P&L Analysis'의 톤 앤 매너(딥 네이비 `#051c2c`, LG 레드 `#a50034`, Serif/Sans 서체 조합)를 엄격히 준수합니다.
  - 좌측 사이드바 국가 선택 시 새로고침 없이 인메모리 JSON이 즉각 바인딩되도록 바닐라 JS 로직을 관리합니다.
  - 표의 가로/세로 Sticky 스크롤 고정과 YoY 증감율에 따른 색상(녹색/적색) 음영 스타일을 유지합니다.
  ```
* **필요 도구**: 파일 생성 및 수정 도구, Playwright MCP 도구 (브라우저 디자인 수동 검증용).

## 2. 작업 지침 & 규칙 (Rules & Constraints)

### [RULE 1] 대용량 엑셀 연산 및 COM 자동화 규칙
- **셀 단위 루프 금지**: 75개 행 및 18개 이상의 컬럼을 지사별로 루프 돌며 개별 셀 값을 읽고 쓰는 연산 방식은 COM 잠금 및 속도 저하를 발생시키므로 절대 금지합니다.
- **일괄 범위 추출**: 반드시 `$sheet.Range("A19:BO293").Value2` (KPI(26년) 시트) 및 `$sheet.Range("A19:AZ293").Value2` (KPI(25년) 시트)와 같이 데이터를 한 번에 .NET 배열로 추출한 후 JS/PowerShell 상에서 가공해야 합니다.
- **프로세스 해제**: Excel 개체 활용 후에는 `finally` 블록을 활용하여 항상 `$wb.Close($false)`, `$excel.Quit()`, 및 COM 객체 해제를 실행하여 백그라운드 프로세스가 남지 않도록 해야 합니다.

### [RULE 2] UI/UX 및 디자인 시스템 가이드
- **Tailwind CSS 적용**: 스타일 구현은 Tailwind CSS CDN 버전을 사용합니다.
- **색상 팔레트**:
  - `primary`: `#051c2c` (사이드바 배경 및 테이블 헤더)
  - `secondary`: `#a50034` (LG전자 아이덴티티 레드, 주요 액센트)
  - `surface`: `#f6faff` (대시보드 메인 배경색)
- **레이아웃 & 오버플로우 방지**:
  - 좌측 w-72 크기의 고정 사이드바 네비게이션과 우측 스크롤이 가능한 메인 컨텐츠 영역으로 구성합니다.
  - 우측 메인 영역 `main` 요소에 `min-w-0` 클래스를 부여하고 `html, body`에 `overflow-x: hidden;` 스타일을 적용하여 가로 스크롤을 오직 `.table-container` 안에서만 동작하도록 제한하고, 첫 번째 고정 열(`sticky-col`)이 사이드바 우측 경계에 항상 완벽히 고정 노출되도록 강제해야 합니다.
  - **테이블 탭 메뉴 선택 기능 (단일 선택)**: 3대 지표 테이블(PSI 지표, 손익 지표, 경쟁 지표)은 KPI 카드 바로 아래 배치된 탭 메뉴를 통해 단일 선택 방식으로 전환되며, 비활성화된 테이블은 `hidden` 처리하여 감춥니다.
  - **테이블 세로 스크롤 제거**: 개별 테이블이 한 화면에 완전히 노출되어 스크롤 없이 볼 수 있도록 `.table-container`의 세로 방향 높이 제한(`max-height`, `overflow-y`)을 제거하고 세로 스크롤바가 생기지 않게 합니다.
- **테이블 고정 (Sticky)**: 데이터 테이블의 헤더(thead)는 상단 스크롤 시 고정되어야 하며, 첫 번째 열(지표 명칭)은 가로 스크롤 시 좌측에 고정(Sticky Left)되어 식별을 도와야 합니다.
- **데이터 테이블 분할 구성**:
  - 기존의 단일 '당해 실적' 표 및 'YoY 증감율' 표를 없애고, 데이터를 **'PSI 지표'**, **'손익 지표'**, **'경쟁 지표'**의 3개 분리된 표로 구성합니다.
  - **PSI 지표 (Table 1)**: Sell-in 수량(OLED, QNED, 신모델, 구모델 포함), Sell-out 수량(OLED, QNED, 신모델, 구모델 포함), 신모델 Sell-in 비중(수량), 신모델 Sell-out 비중(수량), 유통재고(신모델, 구모델 포함), WOS(-4)(신모델, 구모델 포함)를 포함합니다.
  - **신모델 비중 행 들여쓰기**: `신모델 Sell-in 비중(수량)` 및 `신모델 Sell-out 비중(수량)` 행은 `유통재고` 바로 위에 위치하며, 들여쓰기 깊이를 `유통재고`와 동일하게 `indent = 1`로 구성합니다.
  - **비중 행 표기 단위**: 소수점 없이 정수 백분율(`00%`) 형식으로 표기합니다.
  - **WOS 지표 표기 규칙**: WOS(-4) 및 그 하위 모델(신모델, 구모델)은 정수가 아닌 소수점 1자리(예: `7.2`, `-18.7`) 형식으로 고정 표기합니다.
  - **Sell-out 하위 OLED 및 QNED 연산**: 
    - 엑셀 시트의 19~33행에는 Sell-out의 OLED와 QNED 세부 지표가 누락되어 있습니다. 이를 위해 196~293행에서 신모델 OLED(198행) + 구모델 OLED(248행)를 합산하여 Sell-out OLED를 계산하고, 신모델 QNED(213행) + 구모델 QNED(260행)를 합산하여 Sell-out QNED를 계산한 뒤 가상 행으로 주입하여 Sell-in과 동일한 하위 구성을 제공합니다.
    - **2025년/2024년 데이터 수집 시 (KPI(25년) 시트)**: 2025년 시트는 2026년 시트와 지표들의 행 번호(레이아웃)가 서로 다르므로 반드시 다음의 고유 행 번호에서 2025년 실적을 추출해야 정합성이 확보됩니다.
      - 신모델 OLED: **Row 195**
      - 신모델 QNED: **Row 207**
      - 구모델 OLED: **Row 242**
      - 구모델 QNED: **Row 254**
  - **손익 지표 (Table 2)**: 제목을 '손익 지표 (P&L Index)'로 구성하며, Gross매출, G.ASP, 차감, Net매출(제상품), Net매출, 한계이익, 영업이익 등을 포함합니다 (엑셀 행 index 38~67).
    - **Net매출(제상품) 표기**: 신모델(제상품) 위의 Net매출 행의 레이블은 'Net매출(제상품)'으로 수정하여 하단의 전체 합산 'Net매출'과 명확히 구분합니다.
    - **금액/손익 지표 백만 단위 통일**: Gross매출, Net매출(제상품), Net매출, 한계이익(금액), 영업이익(금액) 및 그 하위 항목들은 수치의 크기와 관계없이 항상 `$0,000.0M` (백만 단위 및 소수점 1자리) 형식으로 표기합니다 (예: `$321.4M`, `$0.0M`, `$-0.0M`).
    - **ASP 지표의 소수점 규칙**: 
      - G.ASP($) 및 하위 모델은 소수점 없이 정수로 통일하여 표기합니다 (예: `$661`).
      - N.ASP($) 및 하위 항목은 소수점 1자리를 포함하여 표기합니다 (예: `$660.7`).
    - **차감 및 비율 지표 규칙**: 차감(하위 항목 포함), 한계이익(%), 영업이익(%) 및 하위 항목은 모두 소수점 1자리 `%` 형식으로 통일하여 표기합니다 (예: `27.0%`, `13.1%`).
- **경쟁 지표 (Table 3)**: 제목을 '경쟁 지표 (Competitiveness Indicator)'로 명명하며 전시수량, 전시지수, 시장판가, M/S 등을 포함합니다 (엑셀 행 index 73~93).
  - **지표 명칭 표기 및 구분**: 각 행의 레이블에는 parent category명을 포함하여 명시적으로 구분합니다 (예: `전시수량 (TTL)`, `전시지수 (OLED)`, `시장판가 (LG)`, `M/S (LG)`).
  - **전시지수**: 소수점 한자리(예: `0.6`) 형식으로 표기합니다.

- **요약 카드 및 데이터 수치 표기 규칙**:
  - **수량(Quantity) 분류**: 라벨에 "수량" 단어가 포함된 지표(예: Sell-in 수량, Sell-out 수량)는 화폐 단위가 아닌 정밀 정수(대수) 형태로 출력되어야 하며, 천 단위마다 `,` 콤마가 포함되어야 합니다.
  - **매출/손익(Currency) 분류 및 백만 단위 전환**: 금액(K$) 단위 지표는 원본 USD 값을 `1,000,000`으로 나누어 백만 단위(`M`)로 표시하되, 정수부에 천 단위 `,` 콤마 구분자 및 소수점 1자리를 강제해야 합니다 (예: `$1,254.4M`).
  - **ASP 지표의 예외 스케일링**: G.ASP($) 및 N.ASP($)와 같은 ASP 지표는 엑셀 수식 상에서 원본 USD 값에 `10^6`이 곱해진 수치를 가지므로, 화면 표시 전 값을 `10^6`으로 나눈 뒤 정수부 콤마와 소수점 1자리의 일반 화폐 단위(예: `$660.7`)로 스케일링해야 합니다.
  - **카드 내부 레이아웃 및 여백 규칙**: 요약 카드는 다음 4개의 요소를 개별 행으로 나누어 왼쪽 정렬된 단일 열(수직 누적, Stacked Layout) 형태로 정렬하며, 각 요소 사이에 일정한 간격(`gap-1.5`)을 부여합니다:
    1. **Line 1**: 지표 타이틀 (예: `NET SALES`)
    2. **Line 2**: 실적 데이터 수치 (예: `$1,254.4M` 또는 `2,488,659`)
    3. **Line 3**: YTD 기간 정보 (예: `YTD (6월 누적)`)
    4. **Line 4**: 전년비 증감 배지 (예: `-$8.5M (▼0.7%)` 또는 `-120,750 (▼4.6%)`)
  - **전년비 증감 배지 내 절대 증감액/증감량 병기 규칙**:
    - 금액 지표(`Net Sales`, `영업이익`)와 수량 지표(`Sell-in 수량`, `Sell-out 수량`, `유통재고`)는 증감율 앞에 절대 증감액/증감량(부호 및 천 단위 콤마 포함)을 병기합니다 (예: `-$8.5M (▼0.7%)`).
    - 영업이익율은 비율 지표이므로 절대 차이값 병기 없이 기존 포인트 증감율만 단독 표기합니다 (`▲4.4%p`).
- **지표 유형 자동 판정 규칙**:
